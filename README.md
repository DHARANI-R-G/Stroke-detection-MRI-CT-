# Dual-Modality Deep Learning Framework for Stroke Detection

## Overview

This project presents a dual-modality deep learning framework for automated stroke detection and classification using **MRI and CT brain scans**. The framework combines deep learning, synthetic data generation, feature optimization, and Explainable AI (XAI) to improve classification performance and interpretability.

The two imaging modalities are handled with separate pipelines because they provide different clinical information:

- **MRI:** Used for multi-class classification of Haemorrhagic Stroke, Ischemic Stroke, and Normal cases.
- **CT:** Used for binary classification of Stroke and Normal cases.

## Key Features

- DCGAN-based synthetic image generation for handling class imbalance.
- Transfer learning using multiple state-of-the-art pretrained CNN architectures.
- Vision Transformer (ViT-B/16) for CT classification.
- Variance-based feature filtering and Genetic Algorithm feature selection for MRI.
- MLP-based classification for optimized MRI features.
- Focal Loss to improve learning on difficult/imbalanced samples.
- Cosine Annealing learning-rate scheduling for CT training.
- Explainable AI using attention analysis and gradient-based saliency maps.
- Automated analysis across eight anatomical brain regions.

## MRI Classification

The MRI pipeline performs **three-class classification**:

1. Haemorrhagic Stroke
2. Ischemic Stroke
3. Normal

Five pretrained CNN models are used as feature extractors:

- EfficientNet-B3
- DenseNet121
- ResNet50
- ConvNeXt-Tiny
- Inception-V3

The extracted features are combined and reduced using variance-based filtering and Genetic Algorithm-based feature selection. The selected features are then classified using an MLP with focal loss.

**Reported test accuracy: 81.67%**

## CT Classification

The CT pipeline performs **binary classification**:

- Stroke
- Normal

A pretrained **Vision Transformer (ViT-B/16)** is fine-tuned for the task. DCGAN is used to generate synthetic stroke images to reduce class imbalance. Training uses focal loss, AdamW optimization, and cosine annealing learning-rate scheduling.

**Reported test accuracy: 97.85%**

## Explainable AI

XAI is integrated into both pipelines to make model predictions easier to interpret.

The framework uses:

- Attention analysis
- Gradient-based saliency maps
- Heatmap visualizations
- Region-wise saliency analysis

For CT analysis, eight approximate anatomical zones are examined:

1. Left Cerebellum
2. Right Cerebellum
3. Brainstem
4. Left Temporal
5. Right Temporal
6. Left Frontal
7. Right Frontal
8. Central/Basal Ganglia

The system produces visualizations and textual reports describing which regions contributed most strongly to a prediction.

> **Important:** The XAI region analysis is an algorithmic visualization of model attention/saliency and should not be interpreted as a clinical diagnosis or precise anatomical lesion segmentation.

## Usage

1. Prepare the MRI and CT datasets using the required folder structure.
2. Run the DCGAN data-balancing pipeline.
3. Train the MRI feature extraction and classification pipeline.
4. Train the CT ViT classification pipeline.
5. Run the XAI analysis on the trained models.
6. Review the generated metrics, heatmaps, and explanation reports.

Accuracy

## Limitations

- Results depend on the quality, size, and distribution of the datasets.
- Synthetic images generated by DCGAN may not perfectly represent real clinical cases.
- XAI heatmaps indicate model sensitivity/attention and do not prove that a highlighted region contains a lesion.
- The reported performance should not be interpreted as clinical validation.
- Further testing on independent, multi-center datasets is required before real-world clinical use.
